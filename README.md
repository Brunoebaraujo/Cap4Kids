# Capitalism 4 Kids

Protótipo jogável de estratégia econômica em uma fazenda, construído com React, TypeScript e Phaser.

## O que já funciona

- Mundo de fazenda com apresentação isométrica inspirada em RTS clássicos.
- Produção de trigo e leite com trabalhadores e fila de tarefas.
- Compra de sementes, venda de produção, custos diários e dívida.
- Preços variáveis, inflação e indicador de riqueza criada.
- Concorrentes simulados que mudam preços e patrimônio.
- Console divino para criar chuva, seca, subsídio, inflação e pragas.
- GitHub Actions pronto para publicar o cliente no GitHub Pages.

> O placar multiplayer desta versão usa rivais simulados. Multiplayer real requer o servidor autoritativo descrito em `docs/technical-architecture.md`; GitHub Pages hospeda apenas o cliente estático.

## Executar

```bash
npm install
npm run dev
```
